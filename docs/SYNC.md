# 三步同步 iPhone / iPad

## 1. 下载并打开

[下载 Mac 安装包](https://github.com/luyududu-bot/niannian-macos-todolist/releases/latest/download/niannian-macos.zip)，解压，将**整个「念念」文件夹**放在固定位置，打开其中的 `念念.app`。需要 macOS 26。

首次打开先选择使用方式。**仅在本机使用**会直接进入清单，不申请云端权限；如果不需要手机同步，到此即可。选择**连接 iCloud**时再按以下步骤操作。若稍后再设置，入口在 **… → 使用方式与同步 → 更改使用方式**。

此版本是临时签名，尚无 Apple Developer ID 公证。首次打开可能需要在「系统设置 → 隐私与安全性」针对本应用点「仍要打开」；先确认下载来源。按[苹果的官方说明](https://support.apple.com/zh-cn/guide/mac-help/mh40616/mac)操作，程序不会关闭系统安全保护。

## 2. 点「连接 iCloud」

Mac 与手机使用同一 Apple 账户，在两台设备的 iCloud 设置中开启「提醒事项」。如果选择月度备忘录，也开启「备忘录」。可按[苹果的设备设置步骤](https://support.apple.com/zh-cn/guide/icloud/mmbf52194b5a/icloud)检查。

在念念中点一次 **连接 iCloud**，在 macOS 弹窗中允许访问提醒事项与备忘录。念念会先验证原生读写，再建立清单和可选月度记录。

单一 iCloud 账户自动选定；多个账户时才出现选择。若不需要备忘录，取消「同时保存每月备忘录」。不需要安装快捷指令，也不需要配置 Agent 或 MCP。

## 3. 手机直接勾选

在 iPhone / iPad 打开 **提醒事项**，找到：

- **念念 · 每日**：今天和其他日期的任务。
- **念念 · 长期**：长期目标。

添加或勾选一条任务，稍等片刻，在 Mac 上确认相应变化。念念运行时约每15秒开始检查，实际还取决于 iCloud 和系统响应。手机端由用户在真实设备上完成过同步验证。

**备忘录**中的 iCloud「念念」文件夹按月保存任务与完成状态，采用紧凑排版。这是月度记录，任务修改统一在念念或提醒事项进行。

## 卡住时只检查这几项

| 看到的情况 | 下一步 |
| --- | --- |
| 手机找不到两个列表 | 确认同一 Apple 账户、两端 iCloud 提醒事项已开启；先在 Mac 提醒事项确认列表存在 |
| 拒绝过系统授权 | 在 Mac「系统设置 → 隐私与安全性 → 自动化」检查念念的提醒事项/备忘录权限，再点重试 |
| 提醒事项已连，备忘录失败 | 可以取消月度备忘录，先正常使用任务同步 |
| 收起后找不到清单 | 点悬浮球、菜单栏念念或 Dock 图标；退出应用后需要重新打开 |
| 同一任务两边同时改动 | 在同步设置中选择保留方向，不会默默覆盖 |
| 手动修改了月度备忘录正文 | 会暂停覆盖以保留原文，任务同步继续 |

## 更新时保留数据

退出念念，保留原位置的 **念念资料**，只更新 `念念.app`、`MCP/` 与 `源码/`。不要用新文件夹整体替换包含资料的旧文件夹。

## 随时改为仅在本机使用

在使用方式设置中选择「仅在本机使用」，等待当前同步完成后切换。提醒事项同步与备忘录归档会停用，已有本机任务和云端记录都保留。以后重新选择 iCloud 时，会使用原来的对应关系合并变化；同一字段有冲突时由用户选择。
