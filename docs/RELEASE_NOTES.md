三步开始：下载解压并打开念念 → 点「连接 iCloud」并允许系统授权 → 在 iPhone / iPad 提醒事项中直接勾选。

- 新增首次使用引导；单一 iCloud 账户自动连接，多个账户才需要选择。
- 提醒事项原生勾选双向同步，区分每日任务与长期任务。
- 可选每月一篇备忘录记录，紧凑字号、分组留白，无任务编号。
- 修复恢复列表被删后删除同步卡住的问题。
- 最近30份归档备份、限长日志与过期通信缓存清理。
- 标准本机 MCP，可让不同 Agent 操作同一份任务。

需要 macOS 26；手机与 Mac 使用同一 Apple 账户，并开启 iCloud 提醒事项。同步已在用户的 Mac 和 iPhone 端验证通过，实际仍受 iCloud 延迟影响。

首次打开：本包为临时签名，尚未进行 Apple 公证，macOS 可能要求在「隐私与安全性」中针对本应用确认打开。[查看三步指南](https://github.com/luyududu-bot/niannian-macos-todolist/blob/main/docs/SYNC.md)。

更新已有版本：先退出，保留原位置的「念念资料」，只替换念念.app、MCP 与源码；不要整文件夹覆盖旧资料。

安装包来自公开源码的自动构建，不含作者任务、账户信息或本地配置。SHA256SUMS.txt 提供下载文件的校验值。
