新增明确的使用方式选项：**仅在本机使用** 或 **连接 iCloud**。

- 本机模式直接进入清单，无需 Apple 账户或云端授权，今天/长期任务、悬浮球、外观设置和本机 MCP 均可使用。
- 需要手机同步时，再选择 iCloud，按系统提示授权即可。
- 设置中可以切换；切换为本机模式停止提醒事项同步和备忘录归档，保留已有任务与云端记录。
- 升级不会自动停用现有用户的 iCloud 连接。
- 增加界面行为测试，验证本机选择不会发出云端连接请求。
